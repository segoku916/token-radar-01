How implied value is computed

One function scores every row, from the snapshot's own figures. No protocol name is special-cased, and no row is hand-picked.

implied = round( tvl × base_multiple(category) × (1 + clamp(change_7d, −60, 120) / 100 × 0.5) × (0.6 + min(age_days, 1095) / 1095 × 0.4) × (1 + 0.02 × min(chains, 5)) )

The base multiple is calibrated from the snapshot itself: for each category, the median market-cap-to-TVL ratio of its live-token protocols, clamped to 0.05–3.00. A category with no live comps uses the global median instead. TVL and seven-day growth come from the snapshot; age is the time since the protocol was first listed, the best record of how long it has run with no token (an unlisted age uses 365 days); chain breadth counts the chains a protocol runs on, up to five.
